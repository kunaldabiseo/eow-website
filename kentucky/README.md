## 1. Goal

Each state page should rank for:

- **expert ophthalmology witness {state}**
- **expert ophthalmologist witness {state}**

The design, header, footer and page addresses (URLs) stay exactly as they are. Only the content and the on-page SEO details change.

## 2. What we found on the current location pages

All 45 location pages in the sitemap were checked: 39 US states, District of Columbia, Canada, United Kingdom, South Africa, Puerto Rico and US Virgin Islands.

| Finding | Pages affected |
|---|---|
| Same body text on every page (about 236 words), with only the location name changed | 45 of 45 |
| "ophthalmologist" keyword not used anywhere in the body text | 45 of 45 |
| Meta description is a list of keywords instead of a sentence | Most pages |
| Meta description too long and cut off in Google (163 to 200 characters) | Canada, Oregon, Puerto Rico, United Kingdom, US Virgin Islands, South Africa |
| Typo "medicolega" in the meta description | United Kingdom, US Virgin Islands, South Africa |
| Only the shared site headings (H2), nothing about the location | 45 of 45 |
| No location-specific facts (state rules, cases reviewed there) | 45 of 45 |
| Doctor photo and email icon have no alt text | 45 of 45 |
| Share image (shown when the link is posted on social media or in email) is the email icon | 45 of 45 |
| "Refractive surgery" link in the text goes through a redirect | 45 of 45 |
| Page address spelled "rhose-island" | Rhode Island |
| Page address pattern differs from the other pages (ends in "-dr-todd-lefkowitz") | Rhode Island, Wyoming |

**US states with no page yet (11):** Arkansas, Delaware, Iowa, Maine, Maryland, Nebraska, New Hampshire, North Dakota, South Carolina, Vermont, Wisconsin. Arkansas, Maryland and Wisconsin are listed on the main expert witness page as states where cases have been reviewed.

The full page-by-page list is on the **State Pages** sheet of the spreadsheet.

## 6. Questions for you

1. **Case count:** the main expert witness page says 400+ cases and the current state pages say 100+. Which number is correct?
2. **Image alt text:** the doctor photo and email icon have no alt text. They are shared images, so adding it updates every page that uses them. Should it be added?
3. **Site publisher name:** the SEO plugin lists the website as published by a user called "admin" with a blank image, on every page. Should it show Dr. Lefkowitz instead?
4. **Rhode Island page address:** it is spelled "rhose-island". Should it be corrected, with a redirect from the old address?
